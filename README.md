# clip-ipv6

Clip filesystem ipv6 paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/clip-ipv6/

## Install / run

```bash
git clone https://github.com/theworker02/clip-ipv6.git
cd clip-ipv6
node src/cli.js
node --test
```
